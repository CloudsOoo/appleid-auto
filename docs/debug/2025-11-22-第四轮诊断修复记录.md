## 二、发现问题与修复

### 2.1 路由重复前缀问题（关键修复）

**问题描述**：
API 路由出现双重前缀，如 `/api/v1/auth/auth/register`、`/api/v1/cards/cards/activate`

**根因分析**：
各 endpoint 文件在创建 `APIRouter` 时设置了 `prefix` 参数，而 `api.py` 在 `include_router` 时又添加了相同的 prefix。

**修复方案**：
移除各 endpoint 文件中的 router prefix，由 `api.py` 统一管理路由前缀。

**修改文件列表**：
| 文件 | 修改内容 |
|-----|---------|
| `app/api/v1/endpoints/auth.py` | 移除 `prefix="/auth"` |
| `app/api/v1/endpoints/cards.py` | 移除 `prefix="/cards"` |
| `app/api/v1/endpoints/accounts.py` | 移除 `prefix="/accounts"` |
| `app/api/v1/endpoints/tasks.py` | 移除 `prefix="/tasks"` |
| `app/api/v1/endpoints/share_pages.py` | 移除 `prefix="/share-pages"` |
| `app/api/v1/endpoints/nodes.py` | 移除 `prefix="/nodes"` |
| `app/api/v1/endpoints/proxies.py` | 移除 `prefix="/proxies"` |
| `app/api/v1/endpoints/packages.py` | 移除 `prefix="/packages"` |
| `app/api/v1/endpoints/stats.py` | 移除 `prefix="/stats"` |
| `app/api/v1/api.py` | 为 packages 和 stats 添加 prefix |

**修复前后对比**：
```
修复前: /api/v1/auth/auth/register
修复后: /api/v1/auth/register

修复前: /api/v1/cards/cards/activate
修复后: /api/v1/cards/activate
```
