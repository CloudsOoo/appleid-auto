# Apple ID 自动解锁 & 自动检测系统 - 系统架构设计

## 1. 技术栈选型

### 1.1 后端技术栈
- **Web 框架**: FastAPI 0.104+ (Python 3.11+)
  - 高性能异步框架
  - 自动生成 API 文档 (Swagger/OpenAPI)
  - 原生支持异步操作
  - 类型提示和数据验证 (Pydantic)

- **数据库**: PostgreSQL 15+
  - 可靠的关系型数据库
  - 支持 JSONB 字段存储复杂数据
  - 强大的事务支持

- **ORM**: SQLAlchemy 2.0+
  - 成熟的 Python ORM
  - 支持异步操作
  - 灵活的查询构建

- **缓存**: Redis 7.0+
  - 高性能键值存储
  - 支持多种数据结构
  - 作为 Celery 消息队列

- **任务队列**: Celery 5.3+
  - 分布式任务队列
  - 支持定时任务 (Celery Beat)
  - 任务重试和错误处理

- **认证**: JWT (JSON Web Tokens)
  - python-jose
  - passlib (密码加密)
  - pyotp (2FA)

### 1.2 前端技术栈
- **框架**: Vue 3.3+ (Composition API)
- **UI 库**: Element Plus 2.4+
- **状态管理**: Pinia 2.1+
- **路由**: Vue Router 4.2+
- **HTTP 客户端**: Axios 1.6+
- **构建工具**: Vite 5.0+
- **富文本编辑器**: TinyMCE (自定义 HTML 编辑)

### 1.3 部署技术栈
- **容器化**: Docker + Docker Compose
- **反向代理**: Nginx 1.24+
- **SSL 证书**: Let's Encrypt (Certbot)
- **进程管理**: Supervisor (可选)
- **监控**: Prometheus + Grafana (可选)

### 1.4 开发工具
- **代码格式化**: Black, isort, prettier
- **代码检查**: Pylint, ESLint
- **API 测试**: Pytest, pytest-asyncio
- **类型检查**: mypy

## 3. 核心模块说明

### 3.1 用户认证与授权模块
- **功能**: 用户注册、登录、JWT 令牌管理
- **技术**: FastAPI Security, JWT, bcrypt
- **安全**: 密码加密、令牌刷新、2FA 支持

### 3.2 卡密授权模块
- **功能**: 卡密生成、激活、校验、管理
- **类型**: 按天、按次数、永久
- **特性**: 批量生成、导出、使用记录

### 3.3 权限管理模块
- **功能**: 角色权限、用户权限、动态配置
- **权限项**:
  - 最大账号数量
  - 解锁间隔限制
  - 分享页数量
  - 自定义 HTML 权限
  - 节点数量限制

### 3.4 Apple ID 管理模块
- **功能**:
  - 账号增删改查
  - 批量导入导出
  - 标签分类
  - 状态监控
  - 历史记录

### 3.5 自动解锁模块
- **功能**:
  - 自动检测锁定状态
  - 使用密保自动解锁
  - 自动关闭 2FA
  - 自动修改密码
  - 自动删除设备
  - 自动检测/修改地区、语言、姓名
  - 自动移除"丢失模式"设备

### 3.6 任务调度模块
- **功能**: 定时任务、任务队列、任务分发
- **技术**: Celery + Redis + Celery Beat
- **特性**: 失败重试、节点负载均衡

### 3.7 分享页模块
- **功能**:
  - 多账号分享
  - 密码保护
  - 有效期控制
  - 访问次数限制
  - 随机显示
  - 多模板支持
  - 域名白名单
  - **自定义 HTML** (header/body/footer)

### 3.8 代理池模块
- **功能**:
  - 代理自动轮换
  - 代理健康检查
  - 支持 Socks5/HTTP
  - 失败自动切换

### 3.9 节点管理模块
- **功能**:
  - 节点自动注册
  - 节点健康检查
  - 自动剔除失效节点
  - 任务负载均衡

### 3.10 安全过滤模块
- **功能**:
  - HTML 白名单过滤
  - XSS 防护
  - CSRF 防护
  - SQL 注入防护
  - API 限流
  - 卡密防暴力破解

## 4. 数据流程

### 4.1 用户注册激活流程
```
用户注册 → 输入卡密 → 卡密校验 → 激活权限 →
绑定套餐 → 设置到期时间 → 完成激活
```

### 4.2 Apple ID 自动解锁流程
```
定时任务触发 → 选择待检测账号 → 获取可用节点 →
获取代理 → 检测账号状态 → 判断是否锁定 →
执行解锁流程 → 更新账号状态 → 记录日志 →
通知用户
```

### 4.3 分享页访问流程
```
访问分享页 → 校验密码 → 检查有效期 → 检查访问次数 →
检查域名白名单 → 随机选择账号 → 渲染自定义 HTML →
过滤危险标签 → 返回页面 → 记录访问日志
```

### 4.4 任务分发流程
```
创建任务 → 加入队列 → Celery Worker 获取 →
选择最优节点 → 获取代理 → 执行任务 →
失败重试 → 更新状态 → 返回结果
```

## 9. 部署架构

### 9.1 单机部署
```
Docker Compose
├── Nginx (80, 443)
├── FastAPI (8000) × 1
├── Celery Worker × 2
├── Celery Beat × 1
├── PostgreSQL (5432)
├── Redis (6379)
└── Vue Frontend (静态文件)
```

### 9.2 集群部署
```
负载均衡器 (Nginx)
    ├── API 服务器 1 (FastAPI + Celery Worker)
    ├── API 服务器 2 (FastAPI + Celery Worker)
    └── API 服务器 3 (FastAPI + Celery Worker)

数据层
    ├── PostgreSQL 主库
    ├── PostgreSQL 从库 (读)
    └── Redis 集群 (主从)

任务调度
    └── Celery Beat (单实例)

解锁节点池
    ├── 节点 1 (代理池 + 解锁服务)
    ├── 节点 2 (代理池 + 解锁服务)
    └── 节点 N (代理池 + 解锁服务)
```

## 10. 技术难点与解决方案

### 10.1 Apple ID 自动化
- **难点**: Apple 反爬虫机制
- **方案**:
  - 代理池轮换
  - 请求指纹随机化
  - 请求频率控制
  - User-Agent 轮换

### 10.2 分布式任务调度
- **难点**: 任务分配、失败重试
- **方案**:
  - Celery 分布式队列
  - 任务优先级
  - 指数退避重试
  - 死信队列

### 10.3 高并发处理
- **难点**: 大量用户同时访问
- **方案**:
  - 异步 IO
  - 连接池
  - 缓存机制
  - 负载均衡

### 10.4 数据一致性
- **难点**: 分布式环境数据同步
- **方案**:
  - 数据库事务
  - 乐观锁
  - 分布式锁 (Redis)
  - 消息队列
