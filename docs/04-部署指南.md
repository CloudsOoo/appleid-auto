## 快速开始

### 1. 克隆项目
```bash
git clone https://github.com/CloudsOoo/appleid-auto.git
cd appleid-auto
```

### 2. 配置环境变量
```bash
# 复制环境变量模板
cp backend/.env.example backend/.env

# 编辑环境变量（重要！）
nano backend/.env

# 必须修改的配置：
# - SECRET_KEY: 随机生成的密钥
# - JWT_SECRET_KEY: 随机生成的 JWT 密钥
# - DATABASE_URL: 数据库连接字符串
# - ADMIN_PASSWORD: 管理员密码
```

### 3. 生成密钥
```bash
# 生成 SECRET_KEY 和 JWT_SECRET_KEY
python3 -c "import secrets; print(secrets.token_urlsafe(64))"
```

### 4. 启动服务
```bash
# 启动所有服务
docker-compose up -d

# 查看日志
docker-compose logs -f

# 检查服务状态
docker-compose ps
```

### 5. 初始化数据库
```bash
# 进入后端容器
docker-compose exec backend bash

# 运行数据库迁移
alembic upgrade head

# 创建管理员账号（如果未自动创建）
python scripts/create_admin.py

# 退出容器
exit
```

### 6. 访问系统
- **前端**: http://localhost (或 https://your-domain.com)
- **API 文档**: http://localhost/api/docs
- **Flower 监控**: http://localhost:5555

## 生产环境部署

### 1. 服务器准备

#### 安装 Docker
```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# CentOS
sudo yum install -y docker-ce docker-ce-cli containerd.io

# 启动 Docker
sudo systemctl start docker
sudo systemctl enable docker
```

#### 安装 Docker Compose
```bash
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
docker-compose --version
```

### 2. 配置防火墙
```bash
# Ubuntu/Debian (UFW)
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

# CentOS/RHEL (Firewalld)
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload
```

### 3. 域名配置
```bash
# 配置 DNS A 记录
# your-domain.com -> 服务器 IP

# 修改 Nginx 配置
nano nginx/nginx.conf

# 将 server_name your-domain.com; 改为实际域名
```

### 4. SSL 证书配置（Let's Encrypt）

#### 使用 Certbot
```bash
# 安装 Certbot
sudo apt-get install certbot

# 停止 Nginx（如果正在运行）
docker-compose stop nginx

# 获取证书
sudo certbot certonly --standalone -d your-domain.com

# 证书位置
# /etc/letsencrypt/live/your-domain.com/fullchain.pem
# /etc/letsencrypt/live/your-domain.com/privkey.pem

# 复制证书到项目目录
sudo mkdir -p nginx/ssl
sudo cp /etc/letsencrypt/live/your-domain.com/fullchain.pem nginx/ssl/cert.pem
sudo cp /etc/letsencrypt/live/your-domain.com/privkey.pem nginx/ssl/key.pem

# 重启 Nginx
docker-compose up -d nginx
```

#### 证书自动续期
```bash
# 添加 crontab 任务
sudo crontab -e

# 添加以下行（每天凌晨 2 点检查续期）
0 2 * * * certbot renew --quiet && docker-compose restart nginx
```

### 5. 生产环境配置优化

#### backend/.env 生产配置
```bash
APP_ENV=production
DEBUG=False

# 强随机密钥
SECRET_KEY=<生成的随机密钥>
JWT_SECRET_KEY=<生成的随机密钥>

# 数据库优化
DATABASE_POOL_SIZE=50
DATABASE_MAX_OVERFLOW=20

# Redis 配置
REDIS_PASSWORD=<设置强密码>

# 日志级别
LOG_LEVEL=WARNING

# 限流启用
RATE_LIMIT_ENABLED=True

# 禁用 CORS（生产环境）
CORS_ORIGINS=["https://your-domain.com"]
```

#### Docker Compose 生产配置
```yaml
# docker-compose.prod.yml
version: '3.8'

services:
  postgres:
    restart: always
    deploy:
      resources:
        limits:
          cpus: '2'
          memory: 2G

  redis:
    restart: always
    command: redis-server --requirepass <redis密码>

  backend:
    restart: always
    command: uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
    deploy:
      resources:
        limits:
          cpus: '2'
          memory: 2G

  celery_worker:
    restart: always
    command: celery -A app.tasks.celery_app worker --loglevel=warning --concurrency=8

  nginx:
    restart: always
```

启动生产环境：
```bash
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d
```

## 配置说明

### 数据库配置
```bash
# PostgreSQL 连接字符串格式
DATABASE_URL=postgresql+asyncpg://用户名:密码@主机:端口/数据库名

# 示例
DATABASE_URL=postgresql+asyncpg://postgres:postgres@postgres:5432/appleid_auto
```

### Redis 配置
```bash
# Redis 连接字符串
REDIS_URL=redis://主机:端口/数据库编号

# 示例
REDIS_URL=redis://redis:6379/0

# 带密码
REDIS_URL=redis://:密码@redis:6379/0
```

### Celery 配置
```bash
# Broker URL
CELERY_BROKER_URL=redis://redis:6379/1

# Result Backend
CELERY_RESULT_BACKEND=redis://redis:6379/2
```

### 初始化 Alembic
```bash
# 进入后端容器
docker-compose exec backend bash

# 初始化 Alembic（首次部署已完成，无需执行）
```

## 备份和恢复

### 完整备份脚本
```bash
#!/bin/bash
# backup.sh

BACKUP_DIR="/backup/appleid_auto"
DATE=$(date +%Y%m%d_%H%M%S)

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份数据库
docker-compose exec -T postgres pg_dump -U postgres appleid_auto > $BACKUP_DIR/db_$DATE.sql

# 备份上传文件
tar -czf $BACKUP_DIR/uploads_$DATE.tar.gz backend/uploads

# 备份配置文件
cp backend/.env $BACKUP_DIR/env_$DATE

# 删除 7 天前的备份
find $BACKUP_DIR -name "*.sql" -mtime +7 -delete
find $BACKUP_DIR -name "*.tar.gz" -mtime +7 -delete

echo "备份完成: $BACKUP_DIR"
```

添加到 crontab：
```bash
crontab -e

# 每天凌晨 3 点备份
0 3 * * * /path/to/backup.sh >> /var/log/backup.log 2>&1
```

## 集群部署

### 多节点架构
```
┌─────────────────────────────────┐
│       负载均衡器 (Nginx)        │
└─────────────────────────────────┘
              │
    ┌─────────┼─────────┐
    ▼         ▼         ▼
┌────────┐┌────────┐┌────────┐
│ Node 1 ││ Node 2 ││ Node 3 │
│Backend ││Backend ││Backend │
│Celery  ││Celery  ││Celery  │
└────────┘└────────┘└────────┘
              │
    ┌─────────┴─────────┐
    ▼                   ▼
┌──────────┐      ┌──────────┐
│PostgreSQL│      │  Redis   │
│  主从    │      │  集群    │
└──────────┘      └──────────┘
```

### 配置步骤

#### 1. 负载均衡配置
```nginx
# nginx.conf
upstream backend_cluster {
    least_conn;
    server node1.example.com:8000 weight=1;
    server node2.example.com:8000 weight=1;
    server node3.example.com:8000 weight=1;
}

server {
    location /api/ {
        proxy_pass http://backend_cluster;
    }
}
```

#### 2. 数据库主从复制
```bash
# 主库配置 postgresql.conf
wal_level = replica
max_wal_senders = 10

# 从库配置
primary_conninfo = 'host=master_ip port=5432 user=replicator password=...'
```

#### 3. Redis 集群
```bash
# 使用 Redis Sentinel 或 Redis Cluster
# 配置在 backend/.env
REDIS_URL=redis://sentinel1:26379,sentinel2:26379,sentinel3:26379/0
```

## 故障排查

### 常见问题

#### 1. 容器无法启动
```bash
# 查看日志
docker-compose logs backend

# 检查端口占用
sudo netstat -tulpn | grep :8000

# 重启服务
docker-compose restart backend
```

#### 2. 数据库连接失败
```bash
# 检查数据库状态
docker-compose exec postgres psql -U postgres -c "SELECT version();"

# 检查网络
docker-compose exec backend ping postgres

# 查看数据库日志
docker-compose logs postgres
```

#### 3. Redis 连接失败
```bash
# 测试 Redis 连接
docker-compose exec redis redis-cli ping

# 查看 Redis 日志
docker-compose logs redis
```

#### 4. Celery 任务不执行
```bash
# 检查 Celery Worker 状态
docker-compose logs celery_worker

# 查看任务队列
docker-compose exec backend celery -A app.tasks.celery_app inspect active

# 清空任务队列
docker-compose exec redis redis-cli FLUSHDB
```

#### 5. Nginx 502 错误
```bash
# 检查后端是否运行
docker-compose ps backend

# 检查 Nginx 配置
docker-compose exec nginx nginx -t

# 查看 Nginx 日志
docker-compose logs nginx
```

## 安全加固

### 1. 防火墙配置
```bash
# 只允许必要端口
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow ssh
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable
```

### 2. SSH 加固
```bash
# 编辑 /etc/ssh/sshd_config
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes

# 重启 SSH
sudo systemctl restart sshd
```

### 3. Docker 安全
```bash
# 使用非 root 用户
USER appuser

# 限制资源
deploy:
  resources:
    limits:
      cpus: '2'
      memory: 2G
```
