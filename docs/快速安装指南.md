# 🚀 快速安装指南（小白版）

> 本指南帮助您在 **5 分钟内** 完成系统部署，无需任何技术背景。

---

## 📋 前置要求

只需要安装一个软件：**Docker Desktop**

| 操作系统 | 下载地址 |
|---------|---------|
| Windows 10/11 | [下载 Docker Desktop](https://desktop.docker.com/win/main/amd64/Docker%20Desktop%20Installer.exe) |
| macOS | [下载 Docker Desktop](https://desktop.docker.com/mac/main/amd64/Docker.dmg) |
| Linux | 见下方一键安装命令 |

> 💡 **提示**：Windows 用户安装 Docker Desktop 后需要重启电脑

---

## ⚡ 一键安装

### 方式一：Linux / macOS（推荐）

打开终端，复制粘贴以下命令：

```bash
curl -fsSL https://raw.githubusercontent.com/CloudsOoo/appleid-auto/claude/appleid-auto/main/install.sh | bash
```

或者使用 wget：

```bash
wget -qO- https://raw.githubusercontent.com/CloudsOoo/appleid-auto/claude/appleid-auto/main/install.sh | bash
```

### 方式二：Windows

1. 下载安装脚本：[install.bat](https://raw.githubusercontent.com/CloudsOoo/appleid-auto/claude/appleid-auto/main/install.bat)
2. 双击运行 `install.bat`
3. 按提示操作即可

### 方式三：手动安装（适合所有系统）

```bash
# 1. 克隆项目
git clone -b claude/appleid-auto/main https://github.com/CloudsOoo/appleid-auto.git
cd appleid-auto

# 2. 复制配置文件
cp backend/.env.example backend/.env

# 3. 启动服务
docker-compose -f docker-compose.dev.yml up -d

# 4. 等待 30 秒后访问
# http://localhost:8000/api/docs
```

## 🔧 常用命令

### 查看服务状态

```bash
cd ~/appleid-auto
docker-compose -f docker-compose.dev.yml ps
```

### 查看日志

```bash
# 查看所有服务日志
docker-compose -f docker-compose.dev.yml logs -f

# 只看后端日志
docker-compose -f docker-compose.dev.yml logs -f backend
```

### 重启服务

```bash
docker-compose -f docker-compose.dev.yml restart
```

### 停止服务

```bash
docker-compose -f docker-compose.dev.yml down
```

### 更新系统

```bash
cd ~/appleid-auto
git pull
docker-compose -f docker-compose.dev.yml up -d --build
```

### 完全卸载

```bash
cd ~/appleid-auto
docker-compose -f docker-compose.dev.yml down -v  # 删除数据
cd ~
rm -rf appleid-auto
```

## ❓ 常见问题

### Q: Docker 启动失败？

**A**: 确保 Docker Desktop 正在运行（看任务栏有没有 Docker 图标）

### Q: 端口被占用？

**A**: 修改 `docker-compose.dev.yml` 中的端口映射，例如将 `8000:8000` 改为 `8080:8000`

### Q: 忘记密码？

**A**: 修改 `backend/.env` 中的 `ADMIN_PASSWORD`，然后重启服务

### Q: 如何备份数据？

**A**:
```bash
# 备份数据库
docker-compose -f docker-compose.dev.yml exec postgres pg_dump -U postgres appleid_auto > backup.sql

# 恢复数据库
docker-compose -f docker-compose.dev.yml exec -T postgres psql -U postgres appleid_auto < backup.sql
```

### Q: 如何配置域名？

**A**: 参考 [部署指南](./04-部署指南.md) 配置 Nginx 和 SSL
