# Apple ID 自动解锁系统 - 故障诊断报告

## 📋 问题诊断

### ❌ 发现的问题

| 问题 | 状态 | 影响 |
|------|------|------|
| Docker 未安装或未运行 | ❌ | 无法启动容器化服务 |
| Python 依赖未安装 | ❌ | 无法直接运行后端 |
| 前端未构建 | ⚠️ | Nginx 无静态文件可服务 |

### 🔍 详细分析

#### 1. Docker 环境问题
```bash
$ docker --version
Docker not available
```
**原因**: 当前环境未安装或未启动 Docker
**影响**: 项目设计为容器化部署，无 Docker 无法运行

#### 2. Python 依赖问题
```bash
$ python3 -c "from app.main import app"
ModuleNotFoundError: No module named 'fastapi'
```
**原因**: 虚拟环境或全局环境中未安装依赖
**影响**: 后端无法直接启动

#### 3. 项目架构
本项目采用 **容器化架构**，依赖：
- PostgreSQL (数据库)
- Redis (缓存/队列)
- FastAPI (后端)
- Celery (任务队列)
- Nginx (前端服务)

## ✅ 解决方案

### 方案一：使用 Docker（推荐）

#### 1.1 在有 Docker 的服务器上运行

**一键安装（推荐）**:
```bash
curl -fsSL https://raw.githubusercontent.com/CloudsOoo/appleid-auto/claude/appleid-auto/main/install.sh | bash
```

**手动安装**:
```bash
# 1. 克隆项目
git clone -b claude/appleid-auto/main https://github.com/CloudsOoo/appleid-auto.git
cd appleid-auto

# 2. 启动开发环境
docker compose -f docker-compose.dev.yml up -d

# 或启动生产环境
./scripts/deploy-prod.sh
```

#### 1.2 在当前环境安装 Docker

**Ubuntu/Debian**:
```bash
# 安装 Docker
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 重新登录或执行
newgrp docker

# 验证
docker --version
```

**CentOS/RHEL**:
```bash
sudo yum install -y docker
sudo systemctl start docker
sudo systemctl enable docker
```

**macOS**:
下载并安装 [Docker Desktop](https://www.docker.com/products/docker-desktop)

### 方案二：本地开发模式（不推荐生产）

如果必须在无 Docker 环境运行，需要手动安装所有依赖：

#### 2.1 安装系统依赖

**Ubuntu/Debian**:
```bash
sudo apt-get update
sudo apt-get install -y python3.11 python3-pip python3-venv \
    postgresql-15 redis-server nodejs npm
```

**macOS**:
```bash
brew install python@3.11 postgresql@15 redis node
```

#### 2.2 启动数据库服务

```bash
# PostgreSQL
sudo systemctl start postgresql
sudo -u postgres psql -c "CREATE DATABASE appleid_auto;"

# Redis
sudo systemctl start redis
```

#### 2.3 安装 Python 依赖

```bash
cd backend

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

#### 2.4 配置环境变量

```bash
# 编辑 backend/.env
# 修改数据库连接为本地
DATABASE_URL=postgresql+asyncpg://postgres:postgres@localhost:5432/appleid_auto
REDIS_URL=redis://localhost:6379/0
```

#### 2.5 启动服务

```bash
# 终端 1: 后端
cd backend
source venv/bin/activate
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 终端 2: Celery Worker
cd backend
source venv/bin/activate
celery -A app.celery_app worker --loglevel=info

# 终端 3: Celery Beat
cd backend
source venv/bin/activate
celery -A app.celery_app beat --loglevel=info

# 终端 4: 前端
cd frontend
npm install
npm run dev
```

## 🆘 常见问题

### Q1: 端口被占用
```bash
# 检查端口占用
sudo lsof -i :8000
sudo lsof -i :5432
sudo lsof -i :6379

# 修改端口配置
vim docker-compose.dev.yml  # 修改 ports 配置
```

### Q2: 数据库连接失败
```bash
# 检查 PostgreSQL 容器
docker logs appleid_postgres_dev

# 手动连接测试
docker exec -it appleid_postgres_dev psql -U postgres
```

### Q3: 权限问题
```bash
# 添加用户到 docker 组
sudo usermod -aG docker $USER
newgrp docker
```
