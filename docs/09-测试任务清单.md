## 📝 测试规范

### 后端测试规范
- 使用 pytest 框架
- 使用 pytest-asyncio 处理异步测试
- 使用 pytest-cov 生成覆盖率报告
- 使用 factory_boy 或 fixtures 创建测试数据
- Mock 外部依赖（数据库、Redis、外部 API）

### 前端测试规范
- 使用 Vitest 作为测试框架
- 使用 @vue/test-utils 测试 Vue 组件
- 使用 @testing-library/vue 进行用户交互测试
- 使用 msw 进行 API Mock
- 使用 @playwright/test 进行 E2E 测试

### 测试命名规范
- 测试文件：`test_*.py` (后端) / `*.spec.ts` (前端)
- 测试类：`Test<ModuleName>`
- 测试函数：`test_<action>_<scenario>_<expected>`

### 测试运行命令
```bash
# 后端测试
cd backend
pytest                           # 运行所有测试
pytest tests/unit/              # 运行单元测试
pytest tests/integration/       # 运行集成测试
pytest -k "test_auth"           # 运行特定测试
pytest --cov=app --cov-report=html  # 生成覆盖率报告

# 前端测试
cd frontend
npm run test                    # 运行所有测试
npm run test:unit              # 运行单元测试
npm run test:e2e               # 运行 E2E 测试
npm run test:coverage          # 生成覆盖率报告
```
